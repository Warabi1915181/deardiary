# Dear Diary app icon layers

Locked direction: Morning, handmade notebook, romantic cord tie.

Stack back to front:

1. `01-diary.svg` — warm paper notebook, page edges, fused brown ink
2. `02-botanical.svg` — pressed sage leaf and two small flowers
3. `03-cord-heart.svg` — Romance Accent cord and heart-shaped knot

Icon Composer owns the canvas background (`#F6CFC7`) and all dynamic material,
including highlights, refraction, blur, and shadows. The SVGs intentionally bake
none of those effects.
